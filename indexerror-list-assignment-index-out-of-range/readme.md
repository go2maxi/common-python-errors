# IndexError: list index out of range

## reproduce.py

```python
numbers = [1, 2, 3]
print(numbers[3])
```

## Error message

IndexError: list index out of range

```

## fix.py
```python
numbers = [1, 2, 3]
print(numbers[2])
```

## Reflection

Index 3 was out of range.

```
